# Council

**가장 똑똑한 세 모델이 치열하게 토론하고, 저렴한 일꾼이 그대로 만든다.**

Claude Code · Codex · Gemini CLI가 계획을 놓고 싸우고 서로의 결과를 비판하며, DeepSeek이 합의된 대로 코드를 씁니다. 데스크탑 앱(Windows/macOS/Linux)이고, 이미 로그인해 둔 각 CLI(구독제)를 헤드리스로 호출합니다.

```
                 ┌──────────── 두뇌 (토론 · 계획 · 비판) ────────────┐
                 │  Claude          Codex            Gemini          │
                 │  중재자·모더레이터 기술 장인        현인·큰 그림      │
                 └──────────┬──────────────────────────▲─────────────┘
                     계획·작업 지시                  diff·테스트 결과
                            ▼                          │
                 ┌──────── 손 (구현) ──────┐   git 체크포인트 · 테스트
                 │  DeepSeek (메인 워커)    │ ─────────┘
                 └─────────────────────────┘
```

## 흐름

**팀은 두 가지입니다.** 새 세션 화면 맨 위에서 고릅니다.
- **🛠 제품팀**: 기술 완성도·쓸모·디자인과 매력·쏠림을 따지며 제품을 만듭니다. Claude(중재자)·Codex(집요한 기술 장인)·Gemini(현인)
- **🔬 연구실**: **가설 → 검증** 구조의 탑티어 랩 미팅입니다. 매 라운드 각자 가설을 내고(비판만 하는 턴은 절반짜리), 서로의 가설을 **사고실험**(이상화한 설정 → 각 가설의 예측 유도 → 판정), 수식 유도, 극한·반례, 레퍼런스로 검증합니다. 가설은 H1, H2…, 수정되면 H2′, 근거는 `[CITED]` `[DERIVED]` `[THOUGHT-EXP]` `[MEASURED]` `[CONJECTURE]`로 표시하고, 지어낸 인용은 금지("(인용 미확인)"). PI(Claude)가 매 라운드 **가설 원장**(메커니즘·판별 예측·돌린 사고실험·상태)을 관리하고 다음에 돌릴 가장 판별력 있는 사고실험을 정합니다. 살아남은 가설이 가장 강한 사고실험을 버티고 남은 이견이 판별 실험 하나로 좁혀지면 합의합니다. 평가 축은 새로움·엄밀성·중요성·실현 가능성. 사고실험으로 판별이 안 될 때만 실제 실험으로 가서 연구 계획(가설·베이스라인·ablation·통계·중단 기준) → DeepSeek 실험 구현 → 리뷰를 반복하고, 최종 보고는 논문 형식입니다. Claude(PI)·Codex(엄밀성 담당)·Gemini(넓은 시야의 선임 연구자, Reviewer 2)

진행 방식(자동·토론만·바로 개발)은 두 팀 모두 같습니다. 에이전트끼리는 영어로 토론하고(토큰 절약), 질문·라운드 정리·최종 보고는 한국어로 옵니다.

**🤖 자동 모드 (기본)**: 화두만 던지면 됩니다. 세 모델이 토론하고, 합의 후 모더레이터가 "파일을 만들거나 고쳐야 하는가"를 판단합니다. 필요하면 계획 → 구현으로 넘어가고, 아니면 결론 보고서로 끝냅니다. 첫 라운드가 끝나면 방향을 크게 바꿀 빈 맥락(누구를 위한 것인지, 목적, 취향, 제약)을 최대 3개 **질문**으로 묻고(알림 + [답하기] 버튼), 그 뒤로는 꼭 사람이 정해야 하는 것만 묻습니다. 답을 기다리는 동안에도 밝힌 가정으로 계속 진행하고, 답이 오면 바로 반영합니다.

**평가 기준 (모든 단계 공통)**
- **쓸모**: 누가 이 문제를 실제로 겪는가, 지금은 어떻게 버티는가, 왜 이걸로 갈아타겠는가
- **디자인**: 맞게 동작하는 걸 넘어 쓰기 편하고 보기 좋은가
- **한 모델 취향 쏠림**: 첫 제안에 다 같이 끌려가지 않았는가 → 그렇다면 다른 대안을 반드시 제시

**고급 모델 투입**: DeepSeek이 묵묵히 구현하다가 감성(디자인·매력)이나 기술이 DeepSeek 수준을 넘어서면, 모더레이터가 다음 한 라운드를 Claude(Opus)에게 맡깁니다(`ASSIGN`). 테스트가 2라운드 연속 실패해도 자동으로 투입되고, 끝나면 다시 DeepSeek에게 돌아갑니다. Codex·Gemini는 비평에만 집중하고 구현을 넘겨받지 않습니다.

**🛠 개발 모드**
1. **계획**: Claude·Codex·Gemini가 각자 몰래 계획 → 이름을 불러가며 반박 → Claude가 쟁점 정리 → 합의되면 `PLAN.md` 확정
2. **빌드 루프** (매 라운드)
   DeepSeek 구현 → git 자동 커밋 → 테스트 명령 실행 → Codex·Gemini가 diff와 테스트를 `[BLOCKER]/[MAJOR]/[MINOR]/[UPGRADE]`로 비판 → Claude가 중복 제거·충돌 판정 후 **작업 지시서** 발행 → 다음 라운드 DeepSeek이 지시서대로 수정
3. 리뷰어·모더레이터 전원 AGREE + 테스트 통과 → 최종 보고서 → (선택) push + PR

**💬 토론 모드**: 세 모델만 토론. 블라인드 오프닝 → 반박 → 정리 → 합의 시 `FINAL.md` (선택: GitHub 이슈에 코멘트)

**🔥 무자비 모드 + 최대 라운드 0**: 합의해도 멈추지 않고 합의안을 다시 공격·개선. 직접 멈출 때까지 계속.

**🧑 끼어들기**: 하단 입력창 → 모든 에이전트가 최우선 지시로 받음. 끝난 세션에 보내면 이어서 진행.

## 실전용으로 만든 부분

| 상황 | Council의 대응 |
|---|---|
| CLI가 업데이트돼 플래그가 바뀜 | 세션 시작 시 **실제 호출 점검**. 깨진 에이전트는 이유와 함께 제외, 나머지로 진행 |
| 구독 **사용량 한도** | 해당 모델만 쉬게 하고(재시도 시각 파싱 또는 1→3→10→20→30분) 자동 복귀. 그동안 역할은 다른 모델이 대신 |
| 전원 한도 | 세션이 대기했다가 가장 빠른 복귀 시각에 자동 재개 |
| 네트워크 끊김 | 10초 → 30초 → 60초 자동 재시도 |
| DeepSeek 키 없음 / 다운 | Codex가 자동으로 구현을 대신 |
| 로그인 풀림 | 해당 모델 제외 + 알림. 모더레이터·워커 역할 자동 승계 |
| 앱 종료 / PC 재부팅 / 크래시 | 모든 상태를 원자적으로 디스크에 기록. 다시 열면 세션 목록에서 **▶ 이어서 진행** |
| 워커가 코드를 망침 | 매 턴 git 체크포인트. 타임라인의 **⏪ 되돌리기** 버튼 |
| 사용자가 IDE에서 브랜치를 바꿈 | 다음 구현 전에 감지해서 세션 브랜치로 복귀. 미커밋 변경이 있으면 일시정지 후 알림 |
| 여러 프로젝트 | 프로젝트별 세션을 동시에 실행 (같은 폴더 중복 실행은 차단) |
| 긴 무제한 세션 | 오래된 발언을 모더레이터가 자동 요약해 컨텍스트 유지 (원문은 `transcript.md`에 보존) |
| 설정 실수 | 저장 전 검증, 이전 파일 `.bak` 보관 |
| 대충 말해서 의도가 흐려짐 | **작업 계약**: 내가 한 말은 코드가 **그대로 인용**하고, 모델의 해석은 "가정"으로 분리해 매 구현·리뷰 프롬프트에 넣습니다. 내가 끼어들면 이전 승인은 무효 |
| 리뷰어가 서로 따라 말함 | 같은 시점의 기록(diff·테스트 증거·계약)으로 **병렬 독립 리뷰**. 에이전트별 렌즈: Codex=완성도·보안, Gemini=쓸모·디자인 |
| 지적이 라운드 사이에 사라짐 | `FINDING: [MAJOR]`로 남겨 **FIXED 전까지** 다음 라운드 프롬프트와 결과 카드에 이월 |
| 결과를 과장함 | 종료 이유(`outcome`)·리뷰 승인(`accepted`)·테스트 증거(`verification`)를 분리. 테스트가 없으면 "미검증", 커밋이 바뀌면 "이전 커밋 결과" |
| 검증 안 된 결과가 바로 PR | 합의·승인·검증이 모두 맞을 때만 정식 PR, 아니면 **초안(draft)**. 중단·오류·에이전트 없음은 자동 게시하지 않음 |

## 💻 작업 창

세션 화면 오른쪽(좁은 화면에서는 💻 작업 창 버튼)에 두 부분이 있습니다.
- **🔔 요청**: 나를 기다리는 것만 모읍니다. 답하지 않은 질문, 권한 요청, 로그인이 필요해 제외된 에이전트([로그인] → [다시 참여]), 사용량 한도 대기
- **💻 터미널**: 에이전트별 탭으로 지금 무엇을 하는지(글, 도구 호출, 오류)를 실시간으로 봅니다

에이전트들은 터미널에서처럼 멈춰서 권한을 묻지 않습니다(읽기 턴은 읽기 전용, 구현 턴은 쓰기 허용). 읽기 턴에서 권한 밖의 행동을 하려다 막히면 요청으로 올라오고, Claude·DeepSeek은 **[이 세션 동안 허용]**을 누르면 다음 턴부터 그 명령을 쓸 수 있습니다.

## 🧾 결과를 판단하는 화면

세션이 끝나면 대화 아래에 **결과 카드**가 붙습니다. 모델의 설명보다 사실이 먼저입니다.
- **결과**: 합의됨 / 라운드 한도 / 중단됨 / 에이전트 없음 / 오류 (v0.5.x 기록은 "결과 기록 없음")
- **검증**: `npm test` @ `a1b2c3d` (R4) · 검증됨 / 실패 / 미검증 / 이전 커밋 결과. 테스트가 추적 파일을 바꿨거나 그 뒤 커밋이 움직이면 초록 체크가 아닙니다
- **리뷰 승인**: 리뷰어 투표로 합의했는지 (종료 이유와 별개)
- **바뀐 파일 · 남은 지적**: `FINDING` 중 FIXED 되지 않은 BLOCKER/MAJOR
- **다음 행동**: 이어서 진행 · 게시(정식/초안) · 체크포인트 되돌리기

대화 위의 **📜 작업 계약**은 내 말과 모델의 해석을 구분해서 보여 줍니다. 내 말은 항상 그대로 인용되고, 가정은 기울임체로 표시됩니다.

## 🐙 GitHub

`git` + `gh` CLI를 그대로 사용합니다 (`gh auth login` 한 번).
- **폴더 + 저장소 칸 따로**: 새 세션 화면에서 프로젝트 폴더와 GitHub 저장소(URL 또는 `owner/repo`)를 함께 적습니다
  - 폴더가 없거나 비어 있으면 → 시작할 때 그 자리에 복제 (폴더 칸을 비우면 `~/council-projects/<저장소>`)
  - git 폴더인데 origin이 없으면 → origin으로 연결 · 같은 저장소면 그대로 · 다른 저장소면 시작하지 않고 알려줌
  - 이슈 링크(`…/issues/12`)를 넣으면 그 이슈가 미션이 됩니다
- **이슈 → 미션**: `#12`를 넣으면 제목·본문·최근 코멘트를 미션으로
- **세션 전용 브랜치** `council/<id>`: 원래 브랜치는 그대로
- **자동 PR**: 결과 헤더(결과·검증·테스트한 커밋·남은 지적) + 최종 보고서 + 합의된 계획 + `Closes #12`.
  합의·승인·검증이 모두 맞으면 **정식 PR**, 아니면 **초안(draft)**. 이미 열린 PR도 근거에 맞춰 `gh pr ready` / `gh pr ready --undo`로 정합
- **토론 결과 → 이슈 코멘트**: 합의된 토론만 자동 게시. 그 외에는 결과 카드에서 직접 게시

추천 워크플로: 할 일을 이슈로 쌓기 → 이슈 번호만 넣고 개발 모드 → PR 리뷰 후 머지.

## 설치

1. 각 CLI 설치 후 터미널에서 **한 번씩 실행해 로그인**
   ```bash
   npm i -g @anthropic-ai/claude-code @openai/codex
   claude    # 로그인
   codex     # 로그인
   agy       # 로그인 (Gemini CLI. npm 패키지가 아니라 따로 설치)
   ```
   DeepSeek은 Claude Code CLI를 DeepSeek의 Anthropic 호환 API에 연결해 씁니다. 별도 설치는 필요 없고 **API 키만** 있으면 됩니다.
2. [Releases](../../releases)에서 앱 설치
   - **Windows**: `Council-x.y.z-win-x64.exe` (설치형) 또는 `Council-x.y.z-portable.exe`
   - **macOS**: `.dmg` (서명 안 됨 → 처음 한 번 우클릭 → 열기) · **Linux**: `.AppImage` / `.deb`
3. 앱 → **⚙ 설정 → API 키**에 `DEEPSEEK_API_KEY` 입력. `~/.council/secrets.json`에 본인만 읽을 수 있게 저장되고, 화면에 다시 표시되지 않습니다.
4. 새 세션 → **🔌 실제 호출 점검**으로 네 모델이 모두 ✅인지 확인 → 시작

소스에서 실행: `npm start` (브라우저 http://127.0.0.1:4517) · `npm run desktop` · `npm run mock` (토큰 없이 체험)

### Windows 메모
- `npm i -g`로 설치한 `claude.cmd`/`codex.cmd`를 그대로 인식합니다.
- Codex의 Windows 네이티브 지원은 아직 실험적입니다. 리뷰어 역할(읽기 전용)이라 영향이 작고, 문제가 생기면 자동으로 제외됩니다.
- 테스트 명령은 `cmd.exe`로 실행됩니다 (`npm test`, `pytest -q` 등은 그대로 동작).

## 모델 · 생각 깊이 선택

새 세션 화면에서 에이전트마다 목록에서 고릅니다.
- **Claude**: fable · opus · sonnet · haiku, 생각 깊이 5단계(낮음~최대)
- **Codex**: 설치된 Codex에서 **현재 제공되는 모델 목록을 자동으로 불러오고**, 모델마다 지원하는 생각 깊이만 보여줍니다
- **Gemini** (agy): `agy models`에서 **모델 목록을 자동으로 불러오고**(Gemini 4 Argon, Gemini 3.8 Flash 등), 생각 깊이 3단계(낮음·보통·높음)
- **DeepSeek**: deepseek-chat · deepseek-reasoner
- 목록에 없으면 "직접 입력…"

## 설정 (⚙ → 고급 설정, 또는 `~/.council/config.json`)

```jsonc
{
  "agents": {
    "claude":   { "model": "opus" },                        // 에이전트별 기본 모델
    "deepseek": { "model": "deepseek-reasoner" },
    "codex":    { "args": { "write": ["--sandbox", "workspace-write"] } }  // CLI가 바뀌면 인자 수정
  },
  "turnTimeoutSec": 1800,
  "limitBackoffSec": [60, 180, 600, 1200, 1800],
  "contextBudgetChars": 60000,
  "maxConcurrentSessions": 4
}
```
각 에이전트 정의는 `cmd` + `args.base/read/write/tail` + `modelArgs` + `env`입니다. `read`는 토론·리뷰용(수정 불가), `write`는 워커용입니다. aider, opencode, Qwen Code 같은 CLI도 같은 방식으로 추가할 수 있습니다.

## 파일

```
<project>/.council/runs/<id>/          (git에서 자동 제외)
  session.json  messages.jsonl         상태 (재시작 복구용)
  transcript.md                        사람이 읽는 전체 대화록
  PLAN.md  FINAL.md  summary.md
  turns/                               매 턴 실제 프롬프트와 원본 응답·stderr
~/.council/  config.json  secrets.json  recent.json  logs/council.log
```

## 개발

```bash
npm test          # 가짜 에이전트로 21개 시나리오 e2e (한도·네트워크·인증 실패, 동시 실행, 크래시 복구, 되돌리기 …)
npm run dist:win  # Windows 설치 파일 (Linux/macOS에서도 빌드됨)
git tag v0.3.0 && git push --tags   # GitHub Actions가 Win/Mac/Linux 설치 파일을 Releases에 업로드
```
CI는 push/PR마다 Windows·macOS·Linux에서 e2e를 돌립니다.

## ⚠️ 주의

- 워커는 권한 확인 없이 파일을 수정하고 명령을 실행합니다. git 저장소에서 쓰세요. 기본으로 세션 전용 브랜치에서 작업합니다.
- 무제한 + 무자비 모드는 구독 사용량을 빠르게 씁니다.
- 서버는 `127.0.0.1`에만 열리고, 다른 웹사이트가 로컬 에이전트를 조작하지 못하도록 막습니다.
